# Attention Lab 🔬

Pedagogical and modular implementations of attention mechanisms from scratch in PyTorch.

## Project Structure

```text
attention-lab/
├── src/
│   └── attention_lab/
│       ├── __init__.py
│       ├── attention.py
│       ├── multi_head.py
│       └── masking.py
├── tests/
├── notebooks/
├── app/
├── AGENTS.md
├── AI_TRACKER.md
├── README.md
├── requirements.txt
├── .gitignore
└── LICENSE
```

## Quick Start

### Installation

```bash
git clone https://github.com/vohuunghiaah/attention-lab.git
cd attention-lab
pip install -r requirements.txt
```

### Running Tests

```bash
pytest
```
